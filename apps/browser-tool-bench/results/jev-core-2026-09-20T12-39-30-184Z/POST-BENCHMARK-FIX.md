# 评测结束后的定时器修复

36 次尝试及原始哈希核验全部结束后，才修改 ProfilePilot 的 TaskService。此修复不属于本批测量版本，不回填或删除 T06-driver-r3 的失败。

- 任务已经 completed、partial 或 failed，但 SDK 仍在输出最终回复时，达到时间上限会停止并收尾该次执行，保留原结果，正常释放浏览器；不会再调用只适用于未结束任务的 pause。
- 过期执行或应用退出时不再处理该计时器；异步暂停/收尾失败会写入任务错误记录，避免未处理的 Promise 拒绝终止进程。
- 新增三个回归用例，覆盖 completed / partial / failed 已落盘而 SDK 尚未退出的情况，检查状态保留、停止一次及浏览器释放一次。
