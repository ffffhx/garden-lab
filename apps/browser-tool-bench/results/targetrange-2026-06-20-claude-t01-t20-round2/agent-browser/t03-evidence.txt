  domContentLoaded = 2046ms ; loadEvent = 2100ms

Trace (t03-trace.json) main-thread:
  EvaluateScript dur=800ms url=http://localhost:4399/assets/heavy.js  (synchronous long task = crunchAnalytics)
  HTMLDocumentParser::ExecuteScriptsWaitingForResources 800ms -> script blocked by pending CSS, runs only AFTER blocking.css returns

Conclusion:
  - LCP main cause = blocking.css (render-blocking, ~1200ms TTFB). Per spec it also blocks the following synchronous heavy.js.
  - 2nd = heavy.js 800ms synchronous long task, serially chained after CSS (~1237 + 800 ~= 2064 FCP).
  - hero.svg 1500ms is the slowest single resource but loads in parallel and finishes before first paint -> distractor, NOT the bottleneck.
