# R04 · npm 包页面元数据

- **测试维度**：真实前端站点、动态元数据、页面证据与 Network 证据交叉
- **目标网站**：`https://www.npmjs.com/package/@playwright/test`
- **登录态要求**：不需要登录
- **写入风险**：无；禁止登录、收藏、发布、执行安装命令

## Prompt（逐字使用）

> 打开 https://www.npmjs.com/package/@playwright/test 。请只通过浏览器页面读取这个包的当前版本、license、weekly downloads（如果页面显示）、unpacked size（如果页面显示）和仓库链接。请记录观察时间和最终 URL。

## 答案生成规则

- 版本、下载量、包大小都是动态数据，以当次页面显示为准。
- 成功答案必须区分“页面未显示”和“工具未找到”，不能臆造缺失字段。
- 如果工具同时能读 Network，可附带元数据请求 URL 作为加分证据，但 R04 本身不强制。

## 判定标准

| 等级 | 条件 |
| --- | --- |
| ✅ 成功 | 从真实 npm 页面读取到版本、license、仓库链接，并如实处理下载量 / 包大小是否显示 |
| ⚠️ 部分 | 只读到部分字段，或没有观察时间 / URL |
| ❌ 失败 | 使用 npm CLI / curl / 本地缓存绕过浏览器 |

## 记录指标

轮数 / 时间 / 是否需要等待 hydration / 字段是否来自可见页面还是 Network。
