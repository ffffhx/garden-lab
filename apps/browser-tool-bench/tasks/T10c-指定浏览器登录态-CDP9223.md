# T10c · 指定浏览器登录态（CDP 9223）：复用用户指定 Profile

- **测试维度**：工具能否复用用户明确指定的、已经运行中的浏览器 Profile 登录态，而不是使用工具自管 profile、默认 profile 推断、或新启动托管浏览器。
- **指定浏览器**：`http://127.0.0.1:9223` 暴露的 Chrome DevTools Protocol endpoint。
- **前置条件**：用户已启动 9223 测试 Chrome profile，并且该 profile 已登录 GitHub。
- **安全边界**：只读任务。禁止标记通知已读、回复、关注、star、修改账号设置或执行任何会写真实网站状态的动作。

## 与 T10a / T10b 的分工

- **T10a**：测“默认 / 真实 profile 登录态”这条路线，重点是默认 profile 能否被工具复用。
- **T10b**：测“工具自管专用 profile / state 持久化”这条路线，重点是工具自己起过的 profile 下次能否免登录恢复。
- **T10c**：测“用户指定现成浏览器”这条路线，重点是工具是否能**明确绑定到 `9223`**，并在这个指定 profile 上复用登录态。

T10c 的关键不是“能不能打开 GitHub”，而是“是不是打开在 9223 这个 profile 里”。

## 工具绑定要求

每个工具必须先证明自己控制的是 `9223`，再执行任务。

| 工具 | 允许路径 | 不允许路径 |
| --- | --- | --- |
| agent-browser | `agent-browser --cdp 9223 connect 9223` 后 `get cdp-url` 必须包含 `127.0.0.1:9223` | 自启托管 Chrome、只看 agent-browser session URL |
| bb-browser | `bb-browser --port 9223 status` 必须显示 `cdpPort=9223` / `cdpConnected=true` | 使用默认 bb managed profile |
| Chrome DevTools MCP | 用 `--browserUrl http://127.0.0.1:9223` 启动或连接 | 默认自启 Chrome / 自管 userDataDir |
| playwright-cli | 只能 `attach --cdp http://127.0.0.1:9223` | `open` / 自启 persistent context / state-load 替代 |
| @chrome | 必须能证明 @chrome 控制的 tab 出现在 `http://127.0.0.1:9223/json/list` 里 | 只证明 Codex selected profile 有登录态 |
| @browser | 必须能证明 in-app browser 绑定到 `9223`；若无此能力则记 N-R | 用 in-app 独立浏览器登录或读公共页 |

推荐证明方式：打开一个唯一 URL（例如 `https://github.com/notifications?query=is%3Aunread&t10c=<timestamp>`），再读取 `http://127.0.0.1:9223/json/list`，确认对应 target URL 出现在 9223 target 列表里。若工具本身能直接报告 CDP endpoint，也要记录报告输出。

## Prompt（逐字使用）

> 请只使用用户指定的 9223 Chrome profile。先证明你当前控制的是 `http://127.0.0.1:9223` 这个浏览器，而不是自启或工具托管浏览器。然后打开 `https://github.com/notifications?query=is%3Aunread`，告诉我当前未读通知数量，并列出前 5 条通知所属仓库或标题。全程只读，不要标记已读或修改任何账号状态。如果不能证明绑定到了 9223，请停止并报告 N-R。

## Ground Truth

- 以执行时 9223 profile 中 GitHub notifications 页面实际显示为准。
- 动态字段必须记录观察时间、最终 URL、工具版本和绑定 9223 的证据。

## 判定标准

| 等级 | 条件 |
| --- | --- |
| ✅ 成功 | 明确证明工具绑定到 `9223`，免登录打开 GitHub notifications，未读数量与页面证据一致，列出前 5 条通知所属仓库或标题，且没有写真实账号状态 |
| ⚠️ 部分 | 能证明绑定到 `9223`，但只拿到部分通知信息；或需要非目标工具做轻量复核才能确认绑定；或工具偶发漂移但被 Agent 自己识别并修正 |
| ❌ 失败 | 工具可运行并尝试绑定 `9223`，但实际落到其他浏览器/profile，或撞登录墙，或误写账号状态 |
| N-R | 工具无能力绑定指定 `9223`，运行时不可用，或在绑定阶段崩溃，未进入任务 |

## 记录指标

- 工具版本。
- 绑定 `9223` 的证据：CDP URL、status 输出、9223 target 列表、或等价证据。
- GitHub notifications 最终 URL。
- 未读数量、前 5 条通知摘要。
- 是否出现 profile 漂移、自启浏览器、登录墙或人工打断。
- 是否有任何写状态风险。

## 安全提醒

- 只读 GitHub notifications，不点击会改变状态的按钮。
- 若工具无法证明绑定到 9223，直接停止，不要用其他 profile 代跑。
- 本任务专门用于区分“自管专用 profile 可用”和“指定现成 profile 可用”，所以不能用 T10b 的 state 文件或 persistent context 替代。
