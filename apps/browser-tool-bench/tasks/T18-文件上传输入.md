# T18 · 文件上传与拖拽输入

- **测试维度**：file input、拖拽上传、本地文件路径处理、页面读取结果验证
- **适用工具**：全部；支持 upload/file chooser 的工具更有优势
- **靶场页面**：`/input-lab`

## Prompt（逐字使用）

> 打开 http://localhost:4399/input-lab ，把仓库里的 apps/browser-tool-bench/fixtures/upload-token.txt 上传到页面。上传后告诉我页面解析出的文件名、字节数和 token。

## Ground Truth

- 文件路径：`apps/browser-tool-bench/fixtures/upload-token.txt`。
- 文件名：**`upload-token.txt`**。
- 文件内容：
  - `token=UPLOAD-448`
  - `owner=Bench Upload`
- 字节数：**36 bytes**。
- 页面最终显示：`文件 upload-token.txt，36 bytes，token=UPLOAD-448`。

## 判定标准

| 等级 | 条件 |
| --- | --- |
| ✅ 成功 | 完成真实文件上传，并报出文件名、36 bytes、UPLOAD-448 |
| ⚠️ 部分 | 通过 eval 伪造 File 对象或只读取本地文件内容，没有走页面上传路径 |
| ❌ 失败 | 无法上传或 token/字节数错误 |

## 记录指标

轮数 / token / 时间；记录使用 file input、drag/drop 还是 eval 逃生舱。
