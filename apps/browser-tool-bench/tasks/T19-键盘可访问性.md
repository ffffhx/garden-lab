# T19 · 键盘可访问性

- **测试维度**：键盘导航、focus trap、ARIA/role、可操作控件语义
- **适用工具**：全部；能模拟键盘并检查可访问性树的工具更有优势
- **靶场页面**：`/a11y-modal`

## Prompt（逐字使用）

> 打开 http://localhost:4399/a11y-modal ，点击"打开偏好设置"。请只用键盘 Tab/Shift+Tab 检查弹窗：键盘能否到达并激活"保存偏好"？如果不能，指出具体 DOM/CSS/ARIA 原因，并告诉我鼠标点击保存后会出现的确认码。

## Ground Truth

- 弹窗内 focus trap 只包含带 `[data-trap-focus]` 的元素：输入框 `#notify-email` 和按钮 `#close-modal`。
- "保存偏好" 是 `<div class="fake-button save-preferences" role="button" id="save-preferences">`。
- 它缺少 **`tabindex="0"`**，也没有 `Enter` / `Space` 键盘事件处理，所以键盘无法聚焦/激活。
- 鼠标点击保存后确认码：**`A11Y-204`**。

## 判定标准

| 等级 | 条件 |
| --- | --- |
| ✅ 成功 | 说明键盘到不了保存按钮、指出缺 tabindex/键盘 handler，并报出 A11Y-204 |
| ⚠️ 部分 | 只说 focus trap 有问题，但没定位到 `#save-preferences` 的语义缺陷 |
| ❌ 失败 | 认为键盘可正常保存，或直接鼠标点击后不做可访问性诊断 |

## 记录指标

轮数 / token / 时间；记录是否使用 keyboard、可访问性快照、DOM 属性检查。
