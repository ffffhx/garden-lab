# T20 · 回归稳定性 / Flake Rate

- **测试维度**：重复执行、结果统计、稳定性报告、不要只看单次成功
- **适用工具**：全部；能脚本化重复操作的工具更有优势
- **靶场页面**：`/flake`

## Prompt（逐字使用）

> 打开 http://localhost:4399/flake ，运行页面上的"运行 10 次"检查。请统计通过次数、失败次数、失败轮次和稳定性代码，并判断这个检查是否稳定。

## Ground Truth

- 页面会调用 `/api/flake-check?run=1..10`。
- 第 **3、6、9** 次稳定失败。
- 通过次数：**7/10**。
- 失败次数：**3/10**。
- 稳定性代码：**`FLAKE-307`**。
- 结论：不稳定，flake rate = **30%**。

## 判定标准

| 等级 | 条件 |
| --- | --- |
| ✅ 成功 | 报出 7/10、失败轮次 3/6/9、FLAKE-307、30% flake rate |
| ⚠️ 部分 | 只读页面 summary，但没有列出失败轮次或 flake rate |
| ❌ 失败 | 只跑一次就判断稳定，或统计错误 |

## 记录指标

轮数 / token / 时间；记录是否用循环/脚本自动统计，还是手工读页面表格。
