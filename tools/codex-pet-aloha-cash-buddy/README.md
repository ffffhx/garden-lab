# Aloha Cash Buddy Codex Pet

Install the `aloha-cash-buddy` Codex pet into `$HOME/.codex/pets`.

## Install

```sh
npx @byted-fenghongxin/codex-pet-aloha-cash-buddy
```

The explicit form also works:

```sh
npx @byted-fenghongxin/codex-pet-aloha-cash-buddy add aloha-cash-buddy
```

After installation, restart Codex App or refresh the pet picker if it is already open.

## Publish

This package is configured for the current internal npm registry:

```sh
npm publish
```

For another registry, either edit `publishConfig.registry` in `package.json` or pass `--registry`:

```sh
npm publish --registry=https://registry.npmjs.org --access public
```
